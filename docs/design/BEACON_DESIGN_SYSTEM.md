# Beacon Design System

## Visual Identity

Beacon is a signal-based habit tracker that uses intentional design to help users build and maintain meaningful habits.

### Design Principles

1. **Signal-Focused** — Clear, purposeful moments for habit reflection
2. **Minimal** — Remove friction, keep focus on habits
3. **Intentional** — Design every interaction with purpose
4. **Responsive** — Works seamlessly across devices
